# Website Restyler

Link to create new bot: https://ql.app/l/oL2vuNOh

Gives any website a new visual language. The bot keeps the copy, voice, and page structure word for word, plans a new look (typography, color, spacing, imagery, motion, and hierarchy), and builds it with micro-animations and interactivity. It hands over a live preview, before and after screenshots, and a summary of its visual choices.

Before you send the prompt, replace `{{WEBSITE LINK}}` with the site you want restyled. Works best on Opus 5.5, so switch the bot's model first.
