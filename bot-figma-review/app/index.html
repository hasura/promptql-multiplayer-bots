Figma Design Review

Review a Figma design together

Paste a Figma link. The frames come in here, and PMs and designers drop pins, discuss, and resolve — no Figma seat needed to comment. Push any thread back into the Figma file when you're done.

Frames are fetched with your Figma connection, so the file has to be shared with your Figma account. The first import asks you once to allow this app to call Figma for you.

How it works

1 · ImportAny Figma file or node link. Top-level frames are rendered at 2× and listed per page.
2 · CommentPick a frame, click anywhere to pin a comment. Reply, resolve, reopen. Everyone sees the same board live.
3 · Hand offPush threads to Figma as native comments on the same spot, download the review as markdown, or save it to the bot.
