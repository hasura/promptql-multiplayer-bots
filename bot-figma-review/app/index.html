Design together, with or without Figma

Start a design here and carry it into Figma, or pull a Figma file in and keep working on it here. Either way, PMs and designers pin comments on the same frames and resolve them together — no Figma seat needed to comment.

Start a design here

Open a blank frame, sketch with shapes, text and images, and collect comments as you go. When it's ready, paste it into any Figma file as editable layers.

Pull from Figma

Paste a Figma link. The frames come in here, you can draw on top of them, and comments can be pushed back into the Figma file as native comments on the same spot.

Fetched with your Figma connection, so the file has to be shared with your Figma account. The first import asks you once to allow this app to call Figma for you.

How it works

1 · Start or importBegin from a blank frame, or bring in any Figma file or node link (top-level frames rendered at 2×, listed per page).
2 · Design & commentPress D to draw — rectangles, ellipses, lines, text, images. Press C to pin a comment anywhere. Everyone sees the same board live.
3 · Hand offCopy a frame as SVG and paste it into Figma as editable layers. Push threads to Figma as native comments, download the review as markdown, or save it to the bot.
